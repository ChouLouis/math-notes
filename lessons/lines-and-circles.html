UNIT 01 / 核心觀念筆記

直線與圓

從圓的方程式讀出圓心與半徑，再用圓心到直線的距離判斷相交、相切或相離。

圓：(x − h)² + (y − k)² = r²　｜　點到直線距離：d = |ax₀ + by₀ + c| / √(a² + b²)
01 觀念說明02 自編例題03 常見錯誤04 互動觀察05 自己試試看
01 / UNDERSTAND

觀念說明

圓心與半徑

在圓的標準式中，圓心是 (h, k)，半徑是 r，且 r > 0。若拿到展開式，可以先配方再判讀。

點到直線的距離

對直線 ax + by + c = 0（a、b 不同時為零），將點 (x₀, y₀) 代入分子並取絕對值，再除以 √(a² + b²)。

直線與圓的位置

令 d 為圓心到直線的距離。d < r 時有兩個交點；d = r 時相切，只有一個交點；d > r 時相離，沒有交點。

02 / EXAMPLE · 自編題

跟著算一題

求圓 x² + y² − 4x + 6y − 12 = 0 的圓心與半徑。

(x² − 4x) + (y² + 6y) = 12

(x − 2)² − 4 + (y + 3)² − 9 = 12

(x − 2)² + (y + 3)² = 25

圓心是 (2, −3)，半徑是 5。展開標準式可還原原式；例如 (7, −3) 代入原式也等於 0。

03 / COMMON MISTAKE

常見錯誤

看到 (y + 3)² 就把圓心的 y 座標寫成 3。

標準式是 (y − k)²，所以 y + 3 = y − (−3)，圓心的 y 座標應為 −3。另外，距離公式分子必須取絕對值，距離不會是負數。

04 / EXPLORE

互動觀察

固定圓 x² + y² = 25（圓心為原點、半徑 5），調整直線 3x + 4y = k 的 k。判定依據是 d = |k|/5，不是圖像像素。

圓心到直線距離 d = 2.000

位置關係：相交，2 個交點

藍色是圓，橘色是直線。相切時 d = 5，也就是 k = ±25。

05 / PRACTICE · 自編題

自己試試看

原點 (0, 0) 到直線 3x + 4y − 10 = 0 的距離是多少？

分數可用 / 表示，例如 1/2；不需要輸入變數或算式。

先自己算算看，按 Enter 也可以送出。

先看提示

將 (0, 0) 代入距離公式。分母是 √(3² + 4²)，不是 3 + 4。

查看答案與詳解
d = |3 × 0 + 4 × 0 − 10| / √(9 + 16)
= 10 / 5 = 2

距離為 2；若圓心在原點且半徑也為 2，這條直線就與該圓相切。
