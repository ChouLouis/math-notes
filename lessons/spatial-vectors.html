UNIT 02 / 核心觀念筆記

空間向量

用三個分量表示空間向量，練習長度、內積和夾角，並注意零向量的例外。

|a| = √(a₁² + a₂² + a₃²)　｜　a · b = a₁b₁ + a₂b₂ + a₃b₃

01 / UNDERSTAND

觀念說明

從兩點得到向量

若 A = (x₁, y₁, z₁)、B = (x₂, y₂, z₂)，向量 AB = B − A = (x₂ − x₁, y₂ − y₁, z₂ − z₁)。順序相反，向量方向也相反。

內積與夾角

當 a、b 都不是零向量時，cos θ = (a · b) / (|a||b|)，其中 0° ≤ θ ≤ 180°。兩個非零向量的內積為 0 時，兩者互相垂直。

對兩個非零向量，內積為正時 0° ≤ θ < 90°；內積為負時 90° < θ ≤ 180°。同向時 θ = 0°，反向時 θ = 180°。

02 / EXAMPLE · 自編題

跟著算一題

已知 a = (1, 2, 2)、b = (2, 1, 2)，求內積和夾角的餘弦。

a · b = 1 × 2 + 2 × 1 + 2 × 2 = 8

|a| = √(1 + 4 + 4) = 3

|b| = √(4 + 1 + 4) = 3

cos θ = 8 / (3 × 3) = 8/9

8/9 介於 0 與 1，且兩向量不同向，因此夾角為銳角。以 arccos(8/9) 計算，θ 約為 27.3°。

03 / COMMON MISTAKE

常見錯誤

把 a · b 算成三個分量各自相乘後的向量。

內積的結果是一個數值，要把對應乘積加起來。另外，內積為 0 不表示可以對零向量談「垂直方向」；計算夾角前，必須先確認兩向量都不為零。

04 / EXPLORE

互動觀察

固定 a = (1, 2, 2)，調整 b 的三個分量。內積和夾角由分量公式計算；零向量沒有方向，因此不計算它與其他向量的夾角。

VECTOR LABa = (1, 2, 2)b = (2, 1, 2)

a · b = 8

|b| = 3.000

夾角 θ：27.3°

角度顯示到小數第一位，來自數值計算的近似。

05 / PRACTICE · 自編題

自己試試看

若 a = (1, 2, −1)、b = (2, 0, 3)，a · b 是多少？

分數可用 / 表示，例如 1/2；不需要輸入變數或算式。

先自己算算看，按 Enter 也可以送出。

先看提示

依序相乘再相加：1 × 2 + 2 × 0 + (−1) × 3。

查看答案與詳解
a · b = 2 + 0 − 3 = −1

兩向量都不是零向量，且內積為負，所以夾角為鈍角。
