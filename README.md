# 高中數學觀念筆記

整理「直線與圓、空間向量、三角函數」的核心觀念、自編例題與互動練習。
目前每個單元先做一份重點筆記，不宣稱涵蓋完整課綱。

## 單元與操作

| 單元 | 核心內容 | 互動 |
|---|---|---|
| [直線與圓](./lessons/lines-and-circles.html) | 圓心、半徑、點到直線距離、位置關係 | 調整直線位置，觀察相交、相切、相離 |
| [空間向量](./lessons/spatial-vectors.html) | 分量、長度、內積、夾角 | 改變向量分量，看內積、長度與夾角 |
| [三角函數](./lessons/trigonometry.html) | 單位圓、象限、角度與弧度 | 調整角度，觀察 sin、cos、tan |

首頁可搜尋單元或觀念。每個單元均有可作答的練習、可展開的提示與詳解。

## 技術與開啟方式

原生 HTML、CSS、JavaScript，沒有後端、金鑰或建置需求。
下載並解壓縮後直接開啟 index.html。assets/ 和 lessons/ 必須與首頁保持原本位置。
也可以將檔案上傳到 GitHub，使用 GitHub Pages 公開。

## 檔案安排

- AGENTS.md：AI 接手專案時的規則。
- index.html：首頁與搜尋。
- lessons/：三個單元的 HTML。
- assets/style.css：共用介面。
- assets/script.js：共用判答與各單元計算。
- DEVELOPMENT.md：規則對照、已完成及尚未完成的檢查。

## 之後如何新增內容

將本專案和 AGENTS.md 一起提供給 AI，例如：

> 請先閱讀 AGENTS.md、README.md 與現有單元。新增「指數與對數」筆記，沿用現有內容順序與共用樣式。加入自編例題、互動練習、提示與詳解，同步更新首頁搜尋、單元數及 README.md。保留既有三個單元，列出修改內容與實際測試結果。

如果使用的 AI 工具無法直接讀取檔案，需貼上 AGENTS.md 內容及現有程式，或上傳完整專案；檔案放在 GitHub 並不代表所有 AI 對話都會自動讀到它。

## 測試參考

- 搜尋「相切」「內積」「單位圓」，應分別找到三個單元。
- 直線與圓練習：距離答案 2。
- 空間向量練習：內積答案 -1。
- 三角函數練習：1/2、0.5、2/4 都正確。
- 每題再測錯誤、空白、無效格式及 1/0。
- 相切按鈕：距離為 5，相切、1 個交點。
- 零向量按鈕：夾角未定義。
- 90° 按鈕：sin 為 1、cos 為 0、tan 未定義。
- 點提示與詳解，確認能展開；每個單元能返回首頁。

## 公開方式

檔案放在 Repository 最外層；Settings → Pages → Deploy from a branch → main → / (root) → Save。
以 Pages 顯示的實際網站網址為準，部署完成後再測公開版本。
